# NDQ — Non-Duality

An interactive graph exploring how diverse spiritual traditions, philosophies, and scientific disciplines all point toward the same underlying non-dual truth.

## What It Shows

A radial graph radiates outward from a central **Non-Duality** node into major domains — such as Eastern Philosophy, Abrahamic Religions, and Sciences — and further into their sub-topics and concepts. The structure is a map, not a hierarchy: every path leads back to the same center.

Clicking any node opens a detail page explaining that concept and its relationship to non-duality.

## Tech

- React 19 + Vite + TypeScript
- [React Flow](https://reactflow.dev/) for graph rendering
- Radial layout computed with a custom BFS algorithm
